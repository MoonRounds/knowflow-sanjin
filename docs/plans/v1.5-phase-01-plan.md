## 1. In Scope（承接 v1.5 计划 Phase 1）

- V12 迁移：四表 RENAME、`knowledge_item` 加 `kb_id`/`deleted`、candidate 单值、DROP `knowledge_base_item`、tag 补 `deleted`
- 后端全链路改名 + `modules/document → modules/file`
- Qdrant payload 单值 + RetrievalService 二次校验改 `kb_id`
- API 改 `/documents` + 单值 `knowledgeBaseId`；DTO/Assembler/VO 同步

## 3. 迁移语义（V12__knowledge_document_restructure.sql）

按 ADR 0007 + G6/G7/G8/G11 实现，单事务内完成：

1. `knowledge_item → knowledge_document`（RENAME），加 `kb_id BIGINT NULL` + 索引 `idx_kdoc_kb`，回填（G6），`MODIFY kb_id BIGINT NOT NULL`，加 FK `fk_kdoc_kb → knowledge_base(id)`。
2. 加 `deleted TINYINT NOT NULL DEFAULT 0`，按 G7 从 `status` 回填后 `DROP COLUMN status`；删 `idx_kitem_owner_status`，加 `idx_kdoc_owner_deleted`；`idx_kitem_owner_created → idx_kdoc_owner_created`。
3. `knowledge_chunk → knowledge_document_chunk`（RENAME），列 `knowledge_item_id → knowledge_document_id`，同步唯一约束/索引/FK 名。
4. `knowledge_item_tag → knowledge_document_tag`（RENAME），列 `knowledge_item_id → knowledge_document_id`，同步约束/FK 名。
5. `DROP TABLE knowledge_base_item`（含其 FK/索引；RENAME 后 MySQL 自动解引用旧表名）。
6. `tag` 加 `deleted TINYINT NOT NULL DEFAULT 0` + `active_normalized_name` 生成列（G11），DROP `uk_tag_owner_name` 改 `uk_tag_owner_active_normalized_name`。
7. `knowledge_candidate`：`ai_knowledge_base_ids → ai_knowledge_base_id`、`draft_knowledge_base_ids → draft_knowledge_base_id`，均取 CSV 首值、改可空 VARCHAR（G8）；`ai_tags/draft_tags` 保持 CSV 不动。
8. `file_metadata.knowledge_item_id → knowledge_document_id`（列 + FK 名同步）。

注意：Flyway history 不改写 V1–V11；RENAME 只作用于 V12 起。干净库（空 schema 全量迁移）与存量库（V11 后插数据再迁 V12）各验证一次。

## 4. 后端改名清单

- `modules/knowledge`：`KnowledgeItem→KnowledgeDocument`、`KnowledgeChunk→KnowledgeDocumentChunk`、`KnowledgeBaseItem` 删除、`KnowledgeItemTag→KnowledgeDocumentTag`；entity/mapper/assembler/dto/vo/service/controller/infrastructure 同步。
- 跨模块引用：`modules/extraction`（CandidateConfirmService、ExtractionResult、UpdateCandidateDraftRequest）、`modules/document→file` 全部类、`modules/knowledgebase`（KnowledgeBaseService.ensureNoOrphanedItems 的 JdbcTemplate 改查 `knowledge_document.kb_id`）、`modules/conversation`（javadoc）、`modules/rag`（RetrievalService/RouterService）、`common`（ErrorCode 注释、GlobalExceptionHandler）。
- `modules/document → modules/file`：包路径迁移 + `Document*` 类改名（DocumentConstants→FileConstants、DocumentController→FileController 等）；VO `KnowledgeItemForFileResponse → KnowledgeDocumentForFileResponse`。
- Qdrant payload key 与 filter（G9）；`KnowledgeIndexingService.payload()` 从关联表改 `item.getKbId()`。
- 新增 `KnowledgeDocumentReindexService.reindexAllForOwner(ownerId)`（G13）。

## 5. API 契约

- `/knowledge-items → /documents`；`/knowledge-items/{itemId}/file → /documents/{documentId}/file`。
- `CreateManualNoteRequest/UpdateManualNoteRequest`：`knowledgeBaseIds: string[] → knowledgeBaseId: string`（必填）；`KnowledgeItemResponse` → `KnowledgeDocumentResponse`（`knowledgeBaseIds → knowledgeBaseId`）。
- `UpdateCandidateDraftRequest`：`knowledgeBaseIds → knowledgeBaseId`。
- 上传 multipart：`knowledgeBaseIds` 数组 → `knowledgeBaseId` 单值。
- 重生成 `docs/api/openapi.json`（运行后端 `/v3/api-docs` 归一化导出）→ `npm --prefix frontend run api:generate` 重生成 `generated.ts`。

## 6. 前端契约

- `api/knowledge-items.ts → api/documents.ts`（函数/路径改名）；`api/types/knowledge-item.ts → api/types/document.ts`。
- 引用与跳转改名：`KnowledgeItemDetailView.vue`（仅 API 调用，路由/文件名不动 G4）、`KnowledgeBasesView.vue`（建笔记/上传/列表）、`ChatMessageItem/MessageSourcesPanel`（跳转路径不动）、`FlowView.vue`、`useFlowData.ts`、`api/files.ts`（上传单值 + `getFileMetadataByItem` 路径）。
- `CandidatesView.vue`：库选择器 `el-select multiple → 单选`，`draftKbIds` 单值，`updateCandidateDraft` 传单值；不改布局（G4）。
- 前端测试同步：`knowledge-bases-view.test.ts`、`candidates-view.test.ts`、mock 数据。

## 7. 重建与回归

- `reindexAllForOwner`：对 ACTIVE 且 `(index_status != INDEXED OR indexed_version IS NULL OR indexed_version != content_version)` 的 Document 提交全量索引任务。
- 闭环回归（自动 Router）：上传 → 索引 → 检索 → 引用；提取 → 候选 → 确认 → 沉淀 → 检索。
- Q2 门槛：先实测 embedding（现有配置测试/smoke，不泄露密钥），Qdrant 可达后重建并验证检索命中。

- V12 干净库与存量库均通过；10 Item 回填 `kb_id` 正确；软删状态映射正确；candidate 单值正确。

- UI 布局与交互未变。

## 10. 剩余风险

- 真实存量库若存在多关联/孤儿 Item，migration 报错需人工核对（G6 自守卫会暴露）。
- embedding 实测受本地环境影响，若不可用则重建/检索回归以降级方式记录。
- `KnowledgeBaseService.ensureNoOrphanedItems` 语义反转（ADR 0007）需在改名中一并确认。
