# KnowFlow 设计系统

> 本文档是 KnowFlow 前端视觉语言的**事实源**，与 `frontend/src/styles/tokens.css` 严格对齐。
> 设计稿（`knowflow-preview-v3.html`）曾作为视觉来源，现以 tokens.css 为唯一实现事实源。

## 1. 定位与原则

- **产品**：个人 AI 学习与知识沉淀系统（V1）。
- **视觉语言**：暖纸 × 深墨 × 点缀的「纸感」。像一张有质感的稿纸，而不是冷冰冰的 SaaS 面板。
- **三原则**：
  1. **纸感优先**：表面用暖纸色（`--kf-paper` 系），文字用深墨（`--kf-ink`），少用纯白/纯黑。
  2. **圆润但有力量**：大圆角（8–20px）+ 硬阴影（`box-shadow: 4px 4px 0`）并存，传达亲和与确定。
  3. **内容优先**：AI 对话、知识条目是主角，导航与装饰让位。

## 2. 色彩

### 语义令牌

| 令牌               | 值        | 用途                                 | 对比度说明              |
| ------------------ | --------- | ------------------------------------ | ----------------------- |
| `--kf-paper`       | `#f5f1e8` | 页面主背景                           | —                       |
| `--kf-paper-2`     | `#ebe5d8` | 次级表面（消息气泡、嵌套面板）       | —                       |
| `--kf-paper-3`     | `#eee8dc` | 侧栏背景                             | —                       |
| `--kf-white`       | `#fffdf8` | 卡片/浮层表面（暖白，非纯白）        | —                       |
| `--kf-ink`         | `#191815` | 主文字/深色元素（Element Plus 主色） | 对 paper 约 15:1（AAA） |
| `--kf-muted`       | `#777064` | 次要文字                             | 对 paper ≥ 4.5:1        |
| `--kf-line`        | `#cec4b2` | 分隔线/描边                          | —                       |
| `--kf-line-dashed` | `#c6bfaf` | 虚线分隔（列表）                     | —                       |
| `--kf-hot`         | `#ff5a36` | 强调橙（危险/焦点/动作）             | 对纸底约 4.6:1          |
| `--kf-hot-soft`    | `#ffe0d7` | 强调橙浅底                           | —                       |
| `--kf-red`         | `#c9362b` | 朱红硬阴影、选中态叠层与品牌流线     | 只做装饰底层或大字强调  |
| `--kf-yellow`      | `#f2cf4a` | 高亮黄（新建按钮、mark）             | 只做背景，不与文字共用  |
| `--kf-green`       | `#264f3d` | 深绿（成功/记忆/知识索引）           | 对纸底 ≥ 7:1            |
| `--kf-green-soft`  | `#dbe8d7` | 深绿浅底                             | —                       |
| `--kf-blue`        | `#8ca7e8` | 浅蓝（点缀，少用）                   | 不与正文文字共用        |

### 用途规则

- **主色 = 墨色**：Element Plus 的 `--el-color-primary` 覆盖为 `--kf-ink`，让主按钮/链接与纸面一致，而非默认蓝。
- **功能性颜色不单独传达含义**：状态必须配文字/图标（如「已引用」「已索引」），不能只靠颜色。
- **浅色文字禁忌**：正文不用 `#888/#999` 这类浅灰（对比不足 4.5:1）；次要文字用 `--kf-muted`。

## 3. 字体

| 令牌              | 值                                             | 用途                      |
| ----------------- | ---------------------------------------------- | ------------------------- |
| `--kf-font-round` | `'Nunito', 'Noto Sans SC', 'PingFang SC', ...` | 圆润无衬线，正文/标题统一 |
| `--kf-font-mono`  | `'SFMono-Regular', Consolas, ...`              | 代码、ID、SHA、时间戳     |

### 字号阶梯（`--kf-text-*`）

| 令牌                | 值   | 典型用途                    |
| ------------------- | ---- | --------------------------- |
| `--kf-text-xs`      | 10px | 徽标、eyebrow、状态 tag     |
| `--kf-text-sm`      | 12px | 次级文字、meta              |
| `--kf-text-base`    | 14px | 正文（聊天、笔记）          |
| `--kf-text-lg`      | 18px | 区块标题                    |
| `--kf-text-display` | 46px | 首页大标题（flowView hero） |

- 字重层级：标题 800–900、正文 600–700、次要 700。纸感语言偏厚重，避免细字重。
- 中文字体回退链保证跨平台：`PingFang SC → Hiragino Sans GB → Microsoft YaHei`。

## 5. 阴影与边框

| 令牌                 | 值                        | 用途                           |
| -------------------- | ------------------------- | ------------------------------ |
| `--kf-shadow-card`   | `0 20px 60px rgba(...)`   | 卡片悬浮柔和投影               |
| `--kf-shadow-hard`   | `4px 4px 0 var(--kf-ink)` | 墨色硬边投影                   |
| `--kf-shadow-accent` | `4px 4px 0 var(--kf-red)` | 朱红叠层投影（主操作、选中态） |
| `--kf-border-1`      | `1px solid var(--kf-ink)` | 强描边（workspace、mark）      |

- 硬阴影是纸感签名，但**只在关键交互/激活态使用**，避免到处滥用。
- 常规分隔用 `--kf-line` 细线，不用硬阴影。
- 装饰性叠层统一使用朱红；黄色只保留在处理中状态和知识流主体等语义位置。

## 6. 动效

| 令牌                 | 值                             | 用途           |
| -------------------- | ------------------------------ | -------------- |
| `--kf-duration-fast` | 150ms                          | hover/按下反馈 |
| `--kf-duration-base` | 200ms                          | 一般过渡       |
| `--kf-ease`          | `cubic-bezier(0.4, 0, 0.2, 1)` | 统一缓动       |

- 交互反馈统一 150–300ms；用 `transform/opacity`，避免动画 width/height。
- 流式生成：`live-ring` 用 `pulse`（1s 循环）标识进行中，**同时必须配文字状态**（`sr-only` aria-live），不能只靠颜色/动画。
- 尊重 `prefers-reduced-motion`：tokens.css 已全局降级动画/过渡。

## 7. 组件规范

### 导航 rail（`AppRail.vue`）

- 宽度 `--kf-rail-w: 176px`；窄屏（≤900px）收窄为 72px 图标条（隐藏文字，保留 `aria-label`/`title`）。
- 图标一律内联 SVG（24×24 描边），**禁止 emoji 作图标**。
- 激活态：墨色边框 + 硬阴影 + 3px 右移 + 右上角红点（`--kf-hot`）。
- 每个入口必须真实路由，无假链接。

### 顶栏 mast（`AppMast.vue`）

- 高度 `--kf-mast-h: 64px`，吸顶，`backdrop-filter: blur`，避免顶部品牌区抢占正文空间。
- 品牌 + 日期 + 主 CTA（「新建学习话题」）。

### 对话气泡（`ChatMessageItem.vue` / `ChatView.vue`）

- 用户气泡：暖白底 `--kf-white`、圆角 `18px 5px 18px 18px`。
- AI 气泡：纸色底，`5px 18px 18px 18px`，从左上角「引出」。
- 用户气泡按内容自然伸缩，最大不超过内容区约 72%；短消息不占满整行。
- 流式消息内容区域加 `aria-live="polite"`，让读屏播报增量。
- 历史栏采用 Codex 式抽屉：展开时占据左侧栏位，收起后回收全部内容宽度；`40px` 展开入口与标题组成左侧操作组，固定 `12px` 间距，不以绝对定位覆盖标题，并记忆桌面端选择。
- 对话输入框只由外围容器绘制圆角和边框；内部 textarea 透明无边框，正文、占位文字与光标统一使用 `16px / 24px` 字体指标，外围提供 `20px` 上下留白。
- 常态 `NOT_AVAILABLE / NOT_NEEDED` 不展示；个人知识来源和异常 RAG 状态与消息操作合并为单排底栏。

### 步骤条 / flow 卡片（`FlowSection.vue` / `KnowledgeFlowCard.vue`）

- 6 步流程（对话→识别价值→知识提炼→你的确认→沉淀→再次调用），当前步用深墨填充，完成步用细线。
- 源自设计稿 flowView，展示知识生命周期。

### pill / chip

- 触控目标 ≥44px（`min-height: var(--kf-touch-min)`）。
- 可交互 chip 用 `<button>` + `aria-pressed`；纯展示用 `<span>`，避免误导可点击。

### 表格

- Element Plus 表格宽度自适应，窄屏外层加 `overflow-x: auto` 滚动容器。
- 状态列用 `el-tag`，文案本地化（如「已索引」「已禁用」），不裸显示英文枚举。

### 状态覆盖

- **空**：统一使用自绘「知识沉淀台」插画、页面语义文案和单一下一步操作，不展示 Element Plus 默认插画。
- **加载**：`v-loading` 或骨架屏；流式用占位消息 + `live-ring`。
- **失败**：错误就近显示 + 可恢复动作（重试/刷新）；toast 只用于非阻断反馈。
- **成功**：`ElMessage.success` 短反馈。

## 8. 可访问性基线

| 规则           | 要求                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 触控目标       | ≥44px（`--kf-touch-min`）；Element Plus 按钮默认 40px、窄屏强制 44px |
| 焦点可见       | `:focus-visible` 统一 `--kf-focus-ring`（2px 橙色轮廓 + offset）     |
| 键盘可达       | 自定义点击元素必须 `<button>`/`<a href>` + 键盘事件                  |
| 语义图标       | icon-only 按钮必须 `aria-label`                                      |
| 动态区域       | 流式/轮询/索引状态更新用 `aria-live="polite"`                        |
| 对比度         | 正文 ≥4.5:1；避免浅灰正文                                            |
| 状态不只靠颜色 | 功能色必须配文字/图标                                                |
| 减少动效       | 尊重 `prefers-reduced-motion`                                        |

## 9. 响应式策略

- **桌面主**（≥1024px）：三栏 Chat 工作台（250px + 1fr + 318px）、rail 176px、FlowView 双栏（1fr + 360px）。
- **收窄**（768–1024px）：Chat 两栏（隐藏最右 Inspector）、FlowView 隐藏 aside。
- **基础适配**（<768px）：rail 收窄为图标条；对话框 `width: min(px, 94vw)`；表格横向滚动。
- V1 不做移动专项版；目标是**窄屏可用、无横向溢出**，不承诺移动优先体验。
